# 并发基础概念

并发编程是现代软件开发的核心技能之一。随着多核处理器的普及，单线程程序已无法充分利用硬件资源，掌握并发编程成为构建高性能、高可用系统的必修课。

## 什么是并发

并发是指系统能够同时处理多个任务的能力。在单核 CPU 上，并发通过时间片轮转实现多任务「看似同时」运行；在多核 CPU 上，多个任务可真正同时执行，实现并行。

并发与并行的区别：
- **并发**：同一时间段内处理多个任务，微观上交替执行
- **并行**：同一时刻物理上同时执行多个任务

## 为什么需要并发

1. **提高吞吐量**：利用多核 CPU 并行处理，单位时间内完成更多工作
2. **降低延迟**：I/O 密集型任务可在等待 I/O 时切换执行其他任务
3. **响应性**：GUI 程序、Web 服务器需在处理后台任务时保持前台响应
4. **资源利用**：避免 CPU 空转等待 I/O，提升硬件投资回报率

## 并发编程的挑战

并发引入了单线程程序不存在的复杂性：

| 挑战 | 说明 |
|------|------|
| 竞态条件 | 多线程访问共享数据，执行顺序影响结果正确性 |
| 死锁 | 线程循环等待彼此持有的资源，导致系统停滞 |
| 活锁 | 线程持续重试但始终无法推进 |
| 饥饿 | 低优先级线程长期无法获得 CPU 或资源 |
| 内存可见性 | 线程对共享变量修改的可见性问题 |
| 指令重排 | 编译器和 CPU 优化导致执行顺序与代码顺序不一致 |

## 核心概念

### 临界区
访问共享资源的代码段，同一时刻只允许一个线程执行。

### 互斥
保证临界区同一时刻仅有一个线程进入的机制。

### 同步
协调多线程按预定顺序执行，包括互斥、屏障、事件通知等。

### 原子操作
不可分割的操作，要么完全执行，要么完全不执行，不存在中间状态。
